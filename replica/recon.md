# 분석: Adobe Premiere Pro + After Effects (데스크탑)

범위: 사용자가 실제로 하는 세 가지 — **싱크 수정**(컷·자막·소리 타이밍), **디자인 수정**(자막·글자 모양·위치), **모션 수정**(키프레임·이징·등장/퇴장 효과)
대상: ODDIN 안의 영상 편집기 — AI 작업자가 1차 편집을 만들고, 사용자는 ODDIN 화면(집·회사·원격·폰)에서 손본 뒤 렌더한다.
날짜: 2026-10-10 · 방법: replica-recon(기능·흐름만 새로 짠다. 프리미어·AE의 코드·아이콘·문구·폰트는 쓰지 않는다)

## 사용자 기준 (작업 기록에서)

- 자막: **한 줄**, 자막 사이 **빈 프레임 없이** 이어 붙임, **실제 발화 시작**에 맞춤, 말한 그대로.
- 자막 디자인: **역할마다 다르게**(해설·실제 발화·설명·특수), 장식은 절제. 색·그라디언트 HEX·테두리·그림자·크기·자간을 **숫자로** 맞춤. **폰트 대체는 바로 문제**.
- 컷: **말끝·첫 음절이 잘리면 최우선 결함**, 컷은 파형이 끝난 뒤, 클립 사이 음량 차이 주의, 레퍼런스보다 템포가 느리면 반려.
- 모션: "쫀득하게" — 컷별 프레임 수 조절, 튀는 이징.
- 일하는 방식: 화면을 마우스로 조작하는 컴퓨터 사용은 쓰지 않고 플러그인·스크립트로. 사용자가 고칠 수 있게 연동해서 전달. 확인하지 않은 것을 완료로 보고하지 않음.

## 핵심 흐름

AI가 만든 편집을 열어 **재생하며 어긋난 곳을 찾고, 타이밍·모양·움직임을 몇 프레임·몇 픽셀 단위로 고친 뒤 MP4로 뽑는 것.**

## 흐름

```
F01 자막 싱크 맞추기 (가장 잦음)
    S03 재생하며 어긋난 자막 찾기 -> 재생 헤드를 발화 시작에 -> 자막 앞 가장자리를 재생 헤드로(스냅) -> 다음 자막 앞이 따라오게(빈칸 없이)
    PR 기준 클릭: 찾기 + 끌기 2~3번 (단축키 Q/W 리플 트림을 쓰면 1번)
    edge: 자막이 붙어 있어 하나를 늘리면 다음 것과 겹침, 프레임 단위가 아닌 시간, 파형이 안 보이는 트랙, 같은 시각 겹치는 자막

F02 컷 경계 다듬기 (말끝·첫 음절)
    S03 파형 확대 -> 클립 끝을 파형이 끝난 뒤로 끌기(리플: 뒤 클립 당김) -> 재생으로 확인
    clicks: 확대 1 + 끌기 1 + 재생 1
    edge: 뒤 클립이 붙어 있음(롤링 vs 리플), 원본 범위 끝을 넘어 늘리기, 소리만 따로 엇갈려 있음(L컷)

F03 장면 자르기·지우기
    S03 재생 헤드 -> 자르기(Ctrl+K) -> 지울 조각 선택 -> 리플 삭제(Shift+Delete)
    edge: 자막도 같이 밀려야 함(트랙 잠금/동기화), 빈칸이 남음

F04 소리 엇갈림 맞추기 (말·입 모양, BGM 박자)
    S03 오디오 클립을 프레임 단위로 밀기(Alt+←/→) 또는 슬립
    edge: 비디오와 연결된 오디오, 1프레임 미만

F05 자막 디자인 바꾸기
    S03 자막 선택 -> S07 글꼴·크기·색·테두리·그림자 -> 스타일로 저장 -> 같은 역할 자막 전부에 적용
    clicks: 5~8
    edge: 글꼴 없음(대체 표시), 두 줄로 넘침, 역할별 스타일이 섞임

F06 위치·크기 바꾸기
    S02 레이어를 끌어 옮기기 / 손잡이로 크기 또는 S05·S07 숫자 입력
    edge: 안전 영역, 가운데 맞춤 스냅, 세로(9:16)·가로(16:9) 화면

F07 키프레임 모션 (확대·이동·나타나기)
    S05/S04 스톱워치 -> 재생 헤드 옮기고 값 바꿈(키 자동 생성) -> 키 이동으로 프레임 수 조절 -> S06 이징(쉬운 이징 F9, 그래프)
    clicks: 키 2개 + 이징 1 = 5~7
    edge: 정지(Hold) 키, 들어오는/나가는 이징 따로, 키를 레이어 밖으로 옮김

F08 등장·퇴장 효과 넣기
    S10 사전 설정 끌어다 놓기(페이드·팝·슬라이드) -> 길이 조절
    edge: 모든 자막에 같은 효과, 짧은 자막보다 효과가 김

F09 확인하며 보기
    S02 Space 재생 / J·K·L / ←→ 1프레임 / 구간 반복
    edge: 미리보기가 느림(렌더 필요)

F10 내보내기
    S12 MP4(H.264) 사전 설정 -> 경로 -> 렌더 -> 결과 재생 확인, 자막 SRT 따로 내보내기
    edge: 같은 이름 파일, 렌더 실패, 오래 걸림
```

## 따라 만들지 않는 것 (이유)

- 색 보정(Lumetri)·효과 플러그인·전환 효과 라이브러리·3D·로토·트래킹·멀티캠·프록시 — 사용자가 이 편집기에서 하지 않는 일, 무거운 일은 프리미어·AE로 보낸다.
- Adobe Fonts·Adobe Stock·모션 그래픽 템플릿 마켓 — Adobe가 가진 콘텐츠·구독.
- 프리미어 프로젝트(.prproj)·AE 프로젝트(.aep) 파일을 직접 읽고 쓰기 — 공개되지 않은 형식. 대신 열린 앱에서 플러그인으로 읽거나 SRT·XML로 주고받는다.
- AI 음성 전사(Speech to Text) 자체 — ODDIN에서는 작업자(AI)·로컬 전사 도구가 맡는다.

## ODDIN에 맞게 바꾸는 점

1. **편집 파일은 글(JSON) 하나** — `*.oddin-edit.json`. AI 작업자가 읽고 고치기 쉽고, 사용자는 같은 파일을 편집기로 연다. 바뀌면 편집기가 다시 읽는다.
2. **어디서나 열림** — 집·회사 PC, 원격, 폰(보기·간단 수정). 렌더는 그 파일이 있는 PC에서.
3. **AI에게 부탁** — 편집기 안에서 "자막 전부 2프레임 늦춰", "제목 쫀득하게 튀어나오게"를 그 세션 AI에게 보낸다(선택한 것·재생 헤드 시각을 같이 넘김).
4. **사용자 기준을 기능으로** — 자막 붙여 두기(빈칸 없음), 발화 시작에 맞추기(파형 기준), 한 줄 넘침 경고, 폰트 대체 경고, 역할별 자막 스타일, 프레임 단위 표시, "쫀득" 이징.
5. **프리미어·AE는 무거운 일에** — SRT로 자막 주고받기, 열린 프리미어 시퀀스 가져오기는 다음 단계(어도비 플러그인 이용).
