# 다른 컴퓨터에서 AI Hub 열기

AI Hub는 이 PC(허브 PC)에서만 열리도록 `127.0.0.1:7700`에 묶여 있습니다. 다른 컴퓨터나 휴대폰에서 열 때는 **Tailscale**이라는 비공개 망을 거칩니다. 본인 계정으로 로그인한 기기끼리만 서로 보이고, 주소는 `https://<PC이름>.<tailnet이름>.ts.net/` 꼴의 HTTPS 주소입니다.

> **먼저 알아 둘 것**
> 원격으로 연 허브에서도 작업은 허브 PC에서 **승인 없이** 실행됩니다(`claude --dangerously-skip-permissions`, `codex --dangerously-bypass-approvals-and-sandbox`). 그러니 원격 접속은 곧 "이 PC에서 아무 명령이나 실행할 수 있는 권한"입니다. 본인 기기만 Tailscale에 연결하세요.

## 왜 이 방식인가
- 이 PC는 공유기 없이 인터넷에 바로 연결되어 있고, Windows 방화벽도 꺼져 있습니다. 그래서 "같은 네트워크에서만 열기"를 하려고 서버를 `0.0.0.0`에 열면 **인터넷 전체에 공개**됩니다. 이 방법은 쓰지 않습니다.
- Tailscale을 쓰면 서버는 지금처럼 `127.0.0.1`에 그대로 있습니다. 허브 PC의 Tailscale이 HTTPS 요청을 받아 허브로 넘겨 주고, 허브는 **허용된 주소인지**, **허용된 Tailscale 계정인지** 한 번 더 확인합니다.
- 같은 네트워크든 밖이든 **같은 주소, 같은 방법**으로 엽니다.

## 지금 당장 써야 한다면
설정 전이라도 이미 켜져 있는 **Chrome 원격 데스크톱**으로 허브 PC 화면에 들어가 `http://127.0.0.1:7700`을 열면 됩니다. 대시보드만이 아니라 PC 화면 전체를 원격으로 다루는 방식입니다.

## 처음 한 번 설정하기 (허브 PC)

| 순서 | 할 일 | 비고 |
|---|---|---|
| 1 | 허브 폴더에서 `npm run restart` | 실행 중인 작업이 끝날 때까지 기다렸다가 허브만 다시 시작합니다. 원격 확인 기능이 들어간 새 서버가 떠야 하므로 **꼭 먼저** 합니다. 설정 › 원격 접속에 "서버 재시작 필요"가 보이면 아직 옛 서버입니다. |
| 2 | `npm run remote -- enable --install` | Tailscale을 설치합니다. 관리자 승인(UAC) 창에서 "예"를 누릅니다. 직접 받으려면 <https://tailscale.com/download/windows> |
| 3 | Tailscale에 로그인 | 브라우저가 열리면 Google·Microsoft·GitHub·Apple 계정 중 하나로 로그인합니다. **다른 기기도 이 계정으로 로그인**하게 됩니다. |
| 4 | 허브에서 **설정 › 원격 접속 › 켜기** | 또는 `npm run remote -- enable`. "HTTPS 허용" 안내가 나오면 링크를 열어 한 번 허용한 뒤 **다시 켜기**를 누릅니다. 켜지면 주소가 초록 상자에 나옵니다. |

- 설정 화면은 왼쪽 아래 계정 줄 › **원격 접속**, 또는 `Ctrl+K` 검색에서 "원격 접속"으로도 열 수 있습니다.
- 설정 화면 위쪽의 네 단계(Tailscale 설치 → 로그인·연결 → HTTPS 허용 → 공유 켜기)가 지금 어디까지 왔는지 보여 줍니다. 단계를 마쳤으면 **다시 확인**을 누르세요.
- 설치 직후 `tailscale` 명령이 PATH에 없어도 됩니다. 허브는 `C:\Program Files\Tailscale\tailscale.exe`를 먼저 찾습니다.
- 주소에는 PC 이름이 들어갑니다. 바꾸고 싶으면 4단계 전에 `tailscale set --hostname=<이름>`으로 바꿉니다. 나중에 바꾸면 경고가 뜨고, 원격 접속을 끈 뒤 다시 켜면 새 주소로 바뀝니다.

## 다른 컴퓨터에서 열기
1. 그 컴퓨터(또는 휴대폰)에 Tailscale을 설치합니다. 휴대폰은 앱스토어·플레이스토어의 Tailscale 앱입니다.
2. 허브 PC와 **같은 계정**으로 로그인하고 연결(Connect)합니다.
3. 브라우저에서 허브 주소를 엽니다. 즐겨찾기에 넣어 두면 편합니다.

열리면 왼쪽 위 **AI Hub** 옆에 초록색 **원격** 배지가 붙습니다. 세션 목록, 실시간 진행, 요청 보내기, 이미지 첨부, 경로 복사를 허브 PC와 똑같이 쓸 수 있습니다. 원격 화면에서는 원격 접속을 켜고 끄는 버튼이 보이지 않습니다(허브 PC에서만 바꿀 수 있음).

## 주소 확인하는 법
- 허브 PC의 허브에서 **설정 › 원격 접속**: 켜져 있으면 초록 상자에 주소가 있고, 옆 버튼으로 복사하거나 새 창으로 열 수 있습니다.
- 허브 폴더에서 `npm run remote`: 상태·주소·다음에 할 일을 한국어로 보여 줍니다.
- Tailscale 관리 화면(<https://login.tailscale.com/admin/machines>)의 기기 목록에서 허브 PC 이름을 눌러도 `…ts.net` 이름을 볼 수 있습니다. 주소는 `https://` + 그 이름 + `/` 입니다.
- `http://`, IP 주소(`100.x.x.x`), 다른 이름으로 열면 막힙니다. 반드시 설정 화면에 나온 `https://` 주소를 쓰세요.

## 같은 네트워크 · 외부에서 쓸 수 있는 조건
같은 네트워크에 있을 때나 밖(카페·회사·휴대폰 데이터)에 있을 때나 **방법은 같습니다**. Tailscale이 가능하면 기기끼리 직접 연결하고, 막혀 있으면 Tailscale 중계 서버를 거칩니다. 중계를 거치면 조금 느릴 수 있지만 동작은 같습니다.

필요한 조건:
- 허브 PC가 켜져 있고(절전·최대 절전 아님), Windows에 로그온되어 있고, 허브가 실행 중일 것
  - 로그온할 때 허브를 자동으로 켜려면 허브 폴더에서 `powershell -ExecutionPolicy Bypass -File install-autostart.ps1`
- 허브 PC와 다른 기기 모두 Tailscale이 **연결됨** 상태이고 **같은 계정**(또는 허용한 계정)일 것
- 두 기기 모두 인터넷에 연결되어 있을 것

## 로그인은 언제 하나
허브에는 따로 비밀번호 화면이 없습니다. Tailscale 계정이 곧 로그인이고, 허브는 Tailscale이 알려 주는 계정이 허용 목록에 있는지만 확인합니다. 피할 수 없는 단계는 다음뿐입니다.

| 언제 | 무엇을 | 몇 번 |
|---|---|---|
| 허브 PC 설정 | Tailscale 설치 승인(UAC), Tailscale 로그인, HTTPS 허용 | 각 1번 |
| 새 기기 추가 | 그 기기에서 Tailscale 로그인 | 기기마다 1번 |
| Tailscale 키 만료 | Tailscale이 다시 로그인하라고 알림 | 기본 180일마다 1번(관리 화면에서 허브 PC의 키 만료를 끌 수 있음) |

### 다른 계정을 쓰는 기기를 허용하려면
> 이 방법은 아직 실제 기기로 확인하지 않았습니다. 가능하면 모든 기기를 같은 계정으로 쓰는 편이 간단합니다.

1. Tailscale 관리 화면에서 허브 PC를 그 계정과 **공유(Share)** 합니다.
2. 허브 PC에서 `npm run remote -- allow <그 계정 로그인>`을 실행합니다.
3. 허용을 거두려면 `npm run remote -- revoke <로그인>`. 열려 있던 화면도 2초 안에 끊깁니다.

설정 화면의 **허용 계정**은 몇 개인지만 보여 줍니다. 계정 목록은 화면에 나오지 않습니다.

## 연결 해제
| 하고 싶은 것 | 방법 |
|---|---|
| 원격 접속 잠시 끄기 | 허브 PC의 **설정 › 원격 접속 › 원격 접속 끄기**, 또는 `npm run remote -- disable`. 허브가 먼저 막고, Tailscale 공유도 해제합니다. 열려 있던 원격 화면은 몇 초 안에 끊깁니다. 다시 켜면 그 화면은 저절로 이어집니다. |
| 특정 기기만 빼기 | Tailscale 관리 화면에서 그 기기를 **Remove** 합니다. |
| 기기를 잃어버렸을 때 | 바로 위처럼 그 기기를 Remove 하고, 걱정되면 원격 접속도 끕니다. |
| 완전히 없애기 | 원격 접속을 끈 뒤 Windows 설정 › 앱에서 Tailscale을 제거합니다. |

## 화면에 나오는 안내
- **원격 배지**(왼쪽 위 초록색): 지금 원격으로 보고 있다는 뜻입니다. 누르면 원격 접속 정보가 열립니다.
- **연결 끊김 줄**(가운데 위쪽): 실시간 연결이 3초 넘게 끊기면 나타나고, 이유를 짐작해 알려 줍니다. 허브는 2초마다 다시 연결하므로 원인이 풀리면 저절로 사라지고 "다시 연결됐어요"가 뜹니다.
- **잠금 화면**("이 화면에서는 허브를 열 수 없어요"): 허브가 이 연결을 막은 경우입니다. 오른쪽 위에 막힌 이유 코드가 있고, 아래에 해결 방법이 나옵니다. 고친 뒤 **다시 시도**를 누르세요.

## 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| 주소를 열면 한참 기다리다 "연결할 수 없음" | 이 기기 또는 허브 PC의 Tailscale이 꺼짐, 허브 PC가 꺼짐·절전 | 두 기기 모두 Tailscale 아이콘이 연결됨인지 확인. 허브 PC가 켜져 있는지 확인 |
| 잠금 화면 `remote_off` "원격 접속이 꺼져 있어요" | 허브 PC에서 원격 접속이 꺼져 있음 | 허브 PC에서 설정 › 원격 접속 › 켜기 |
| 잠금 화면 `remote_host` "이 주소로는 허브를 열 수 없어요" | 허용되지 않은 주소(IP 주소, 옛 PC 이름 등)로 열었음 | 설정 화면에 나온 `https://…ts.net/` 주소로 열기. PC 이름을 바꿨다면 허브 PC에서 끄고 다시 켜기 |
| 잠금 화면 `remote_user` "허용되지 않은 Tailscale 계정이에요" | 이 기기의 Tailscale 계정이 허용 목록에 없음, 또는 공개(Funnel) 주소로 들어옴 | 같은 계정으로 로그인. 다른 계정이면 위 "다른 계정을 쓰는 기기를 허용하려면" |
| 잠금 화면 `remote_socket` | Tailscale을 거치지 않은 연결 | `config.json`의 `host`가 `127.0.0.1`인지 확인. 다른 값으로 바꾸지 말 것 |
| 설정 › 원격 접속에 "서버 재시작 필요" | 원격 기능이 없는 옛 서버가 실행 중 | 허브 폴더에서 `npm run restart` |
| 켜기를 누르면 "HTTPS 인증서를 허용해 주세요" | Tailscale 계정에서 HTTPS가 아직 꺼져 있음 | 안내 링크(<https://login.tailscale.com/admin/dns>)에서 HTTPS Certificates를 켜고 **다시 켜기** |
| "443 포트를 이미 다른 서비스가 쓰고 있어요" | 이 PC에 다른 Tailscale 공유가 있음 | 그 공유를 계속 쓸 거면 그대로 두기. 덮어쓰려면 `npm run remote -- enable --force`(원래 공유는 끊김) |
| "Funnel이 켜져 있어요" 경고 | 인터넷 공개 공유가 켜져 있음 | 허브는 공개 요청을 막지만, `tailscale funnel` 설정을 꺼 두세요 |
| "PC 주소가 바뀌었어요" 경고 | Tailscale PC 이름이 바뀜 | 허브 PC에서 원격 접속을 끄고 다시 켜기 |
| 복사 버튼이 안 됨 | `http://` 주소로 열었음 | `https://` 주소로 열기 |
| 화면 위에 "허브와 연결이 잠깐 끊겼어요"가 계속 | 허브가 다시 시작되는 중이거나 네트워크가 불안정 | 잠시 기다리기. 계속되면 **새로고침**. 허브 PC에서 허브가 실행 중인지 확인(`start-hub.cmd`) |

더 자세한 상태는 허브 PC에서 `npm run remote`(사람용) 또는 `npm run remote -- status --json`(전체 정보)으로 볼 수 있습니다.

## 하지 말 것
- 서버 주소(`config.json`의 `host`)를 `0.0.0.0`이나 공인 IP로 바꾸기 — 이 PC는 방화벽이 꺼진 채 인터넷에 바로 연결되어 있어 그대로 공개됩니다.
- 공유기 포트 열기, `tailscale funnel`, ngrok·trycloudflare 같은 공개 터널
- 원격 접속을 켠 채 다른 사람의 기기를 같은 Tailscale 계정에 로그인시키기

## 명령 모음 (허브 폴더에서)
| 명령 | 하는 일 |
|---|---|
| `npm run remote` | 상태·주소·다음 단계 보기 |
| `npm run remote -- enable [--install] [--force]` | 원격 접속 켜기(`--install`: Tailscale이 없으면 설치, `--force`: 443 충돌 덮어쓰기) |
| `npm run remote -- disable` | 원격 접속 끄기 |
| `npm run remote -- allow <로그인>` / `revoke <로그인>` | 다른 Tailscale 계정 허용·취소 |
| `npm run restart` | 작업이 없을 때 허브만 다시 시작 |

원격 설정은 `data\remote.json`에 저장됩니다. 직접 고치지 말고 위 명령을 쓰세요. 바꾸면 허브가 재시작 없이 바로 반영합니다.
