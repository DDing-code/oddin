%%MESSAGE%%

이렇게 하면 열려요

  1. 허브 PC에서 허브를 열고 설정 › 원격 접속에서 켜기를 누르세요. 터미널에서는 허브 폴더에서 npm run remote -- enable로도 켤 수 있어요.
  2. 켜졌으면 이 페이지에서 다시 시도를 누르세요.

이렇게 하면 열려요

  1. 허브 PC의 설정 › 원격 접속에 보이는 주소(https://PC이름.tailnet이름.ts.net/ 꼴)로 여세요. IP 주소나 다른 이름으로 열면 막혀요.
  2. 허브 PC의 Tailscale 이름을 바꿨다면, 허브 PC에서 원격 접속을 한 번 끄고 다시 켜야 새 주소가 등록돼요.

이렇게 하면 열려요

  1. 이 기기의 Tailscale이 허브 PC와 같은 계정으로 로그인되어 있는지 확인하세요. 작업 표시줄이나 메뉴 막대의 Tailscale 아이콘에서 계정을 볼 수 있어요.
  2. 다른 계정을 써야 하면 허브 PC에서 npm run remote -- allow 그-계정-로그인으로 허용하세요.
  3. 공개 주소(Funnel)로는 열 수 없어요. 허브는 본인 tailnet 안의 기기만 받아요.

이렇게 하면 열려요

  1. 원격 접속은 Tailscale 주소로만 받아요. 허브 PC의 설정 › 원격 접속에 보이는 주소로 여세요.
  2. 허브 PC 관리자라면 config.json의 host가 127.0.0.1인지 확인하세요. 다른 값으로 바꾸면 인터넷에 그대로 열릴 수 있어요.

이렇게 하면 열려요

  1. 다른 사이트에서 보낸 요청은 막아요. 허브 주소를 주소창에 직접 입력해서 여세요.

안내

  1. 원격 접속 설정은 허브 PC 앞에서만 바꿀 수 있어요. 원격에서는 상태만 볼 수 있어요.

확인할 것

  1. 허브 PC에서 설정 › 원격 접속 상태를 확인하세요. 문제가 계속되면 허브 폴더에서 npm run remote를 실행해 안내를 보세요.
다시 시도
원격으로 연 허브에서는 허브 PC에서 승인 없이 작업이 실행돼요. 그래서 본인 Tailscale 계정의 기기만 열 수 있게 막아 두었어요.
